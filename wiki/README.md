# 离线文集（电脑阅读）

这是给电脑用的阅读方式：像本地 wiki，**点侧栏即达**，正文连续滚动，没有 EPUB 翻页。

## 打开

在仓库根目录：

```bash
python3 ebook/build_wiki.py --serve
```

浏览器打开 http://127.0.0.1:8765/

也可以直接用浏览器打开 `wiki/index.html`（不经过服务器）。若主题或本地存储异常，用上面的本地服务器更稳。

重新生成（改了文章之后）：

```bash
python3 ebook/build_wiki.py
```

## 快捷键

| 键 | 作用 |
|---|---|
| `/` | 搜索篇名与小节 |
| `J` / `→` | 下一篇 |
| `K` / `←` | 上一篇 |
| `Esc` | 清空搜索 |

侧栏「主题」可切换深浅色。
