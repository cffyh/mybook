# 实践｜实战｜工程｜实干——理解之外的活，为什么不能只用一个词

**缘起**：写到 [拆掉舞台之后](../关键文章/学科/拆掉舞台之后——超弦、圈量子引力、弦网，与高一维的全息密码.md) 时碰上一个老问题：如同 [概念与技能](../书稿%205/概念与技能——两种学习，同一种以小控大.md) 分得很开，**理解科学理论是一回事，去探索和应用科学是另一回事**——后者要靠技术、工具和社会条件，因为已经进入工程和真实世界。可落到字面上，立刻卡在选词上：「实战」带着“战”，太场景化；「实践」又太像哲学大词或教科书评语，听不见工具、摩擦与代价。本篇只做**选词闸**，把全书这一簇近义词摊开辨清，供他篇引用，不重改旧篇标题。
**用途**：当你要说「读懂之外、在真实世界里把事推进和做成的那种能力」，却觉得说“实践能力”太虚、说“实战能力”太窄时，先过这一闸，按场景选词。

---

## 一、为什么“实践”和“实战”都不太趁手

这两个词之所以总让人别扭，不是人挑剔，而是它们在现代中文里各自背着很重的历史包袱。

### 1. “实践”：被哲学大词和口号占满了

英文里的 *practice* 本来很贴地——医生执业叫 *medical practice*，工程师干活叫 *engineering practice*，法律实务叫 *legal practice*，天然包着工具、规程、手感与现场约束。

但翻成中文「实践」以后，这个词主要停留在两个地方：一是哲学认识论的最高总名（「认识与实践」「实践是检验真理的唯一标准」），二是学校与体制里的套话（「社会实践」「理论联系实践」）。

层级一高、范围一宽，颗粒度就丢了。说一个人有“实践能力”，听上去像期末评语，**听不见材料公差，听不见预算和工期，听不见工具链，也听不见协作和代价**。它适合留在认识论总层——像 [实践：渺小与宏大之间的纽带](../书稿%203/接缝-实践/实践-渺小与宏大之间的纽带_独立成文.md) 里那样，用来指「人与世界发生互动的总通道」——却很难扛起日常干活时的具体分量。

### 2. “实战”：借了“战”来补实感，顺手带进了对抗

大家嫌“实践”太虚，于是借了军事词「实战」，想把那股**真刀真枪、要付代价、不可重来、对象会反作用**的实感拉回来。

用在商业竞争、谈判、抢生态位、带团队打硬仗时，这个词非常准——那些地方本来就有对手、有输赢、有淘汰。你在 [实战能力——方法之外的那一层](../书稿%205/总论/3%20实战能力——方法之外的那一层.md) 里写的四样东西（代价与勇气、不确定与运气、时间与韧性、竞争策略），恰恰需要这个“战”字来把「真金白银下注」和「无风险练习」劈开。

可一旦挪到**科学探索、大型实验、工程研发、医疗、制造**里，“战”字的零和对抗与兵法味就跑偏了。物理学家花二十年建对撞机、造低温探测器，工程师把芯片良率从 60% 推到 95%，他们不是在跟敌军拼刺刀，而是在和物理极限、工艺窗口、预算、团队分工打交道。这里同样充满代价与不确定，却并不以「打败一个敌手」为骨架。把这一切全塞进「实战」，词就显得太窄、太紧绷。

## 二、理解之外的那块活，拆开看其实是四样东西

先把想指的对象本身看清，再回头挑词。

对照「理解理论（在脑子里把概念、图像与逻辑走通）」，迈出这一步之后，人迎面撞上的其实是四样东西：

1. **真实约束**：物理极限、材料性能、公差、时间窗口、资源上限——纸上可以“忽略摩擦”，现实里一项都省不掉。
2. **技术与工具**：仪器、设备、工艺、方法库、软件与流程——没有趁手的工具，连问题的门都摸不到。
3. **社会条件**：组织、分工、经费、制度、利益分配、沟通与信任——凡是超过一个人力气的事，都必须靠社会结构把它托起来。
4. **不确定性与代价**：要押时间、押资金、扛失败、熬周期，且结果不打包票。

只有在一部分场景里，才会在这四样之上，**额外叠加第五样**：

5. **有敌手、会还手的对抗**：商业竞争、博弈、谈判、资源争夺——对象不是安静的自然规律，而是带着独立意志、会反制你的另一群人。

用一个词同时装进前四样和第五样，要么太虚（装得下却没手感），要么太窄（有手感却把第五样误当成全部）。这就是卡壳的根源。

## 三、候选词挨个过筛

把中文里严肃可用的一排词拉出来，对照上面五条逐一检验：

| 候选词 | 强在哪 | 卡在哪 | 在本书里的定位 |
|---|---|---|---|
| **实践** | 哲学总名，层级最高，与「认识」对仗最严 | 教科书与口号味重，听不见工具、成本与手艺 | 留给**认识论总层**（人与世界互动的总纽带），少用“实践能力” |
| **实战** | 自带代价、风险、不可重来、会还手的实感 | 自带“战”（对抗、敌手、零和），放科研与建设里太窄 | 收回**多主体竞争与博弈场**（商业、谈判、抢生态位） |
| **实作 / 实操** | 与「理论」对仗最工整（理论 vs 实作） | 偏「个人动手操作」，撑不起经费、组织、制度等社会条件；“实作”在大陆日常语感略小众 | 只指**个人上手操作**那一截（对应技术、手感） |
| **实务** | 天然包着工具、流程、人情与社会规则（法律实务、医学实务） | 偏**成熟行业的常规事务**，装不下前沿探索与无人区开拓 | 成熟职业的日常运作 |
| **工程** | 最精准包进**技术＋工具＋约束＋组织协作**（广义工程本就包含预算、进度与人） | 日常语感容易被窄化成“工科造物”，盖不住人与人的博弈 | **对物、对未知、对系统**的主场词（探索、实验、研发、应用） |
| **落地** | 与「悬在空中、纸上谈兵」反差极强 | 偏商业／互联网口语；适合「应用」，不适合「前沿科学探索」（造对撞机不太像“落地”） | 只用于「把已有想法／方案在现实里做出来」 |
| **实干** | 去“战”味、去哲学味，探索、工程、商业全装得下；且直接接上书稿 3《理性与实干》 | 日常容易被听成“老黄牛式的勤劳肯干”（偏态度，不像驾驭工具与局面的高阶能力） | **跨场景总词候选 A**——需明确重新钉义：不是埋头苦干，是在真实约束、工具与社会条件里把事往前推的功夫 |
| **做事 / 成事** | 去“战”味，一听就懂为何需要工具、资源与人；书稿 1 第八部即用「做事」 | 「做事」略平淡；「成事」略带职场味，且对「可能长期无果的前沿探索」稍显功利 | **跨场景总词候选 B**——日常平实表达最顺口，讲科学探索时慎用“成事” |
| **临场** | 精准指「信息不全、具体时空、此时此地的出手」 | 偏「当下那一局的应对」，包不住十年磨一剑的大工程与长期积累 | 专指**现场决策与应对**（见《临场》） |
| **实力** | 精准指「被结果称过重、带得走的存量本钱」 | 指的是**沉淀出的筹码**，不是「下场干活那一类活动」本身 | 专指**方法→技术→能力→实力**的终点存量 |

## 四、最干净的解法：一总两分，各归其位

不必硬造一个怪词去包打天下，也不必把全书已经写熟的旧篇标题推倒重写。看清上面那张表，其实全书自己的骨架已经给出了一条最干净的切法——**一总两分，与「两块世界」一一对齐**（见 [以小控大的目的与方法](../书稿%205/以小控大的目的与方法——两块世界，实战与修心.md)）：

```
                  哲学总层（人与世界互动的总通道）
                            │
                         【实践】
                            │
              跨场景总词（理解之外、在真实世界推进事的功夫）
                            │
                    【实干】（日常可说「做事」）
                   ╱                    ╲
      对自然·对未知·对系统              对人·对对手·对竞争
   （约束＋技术＋工具＋组织）         （再加：敌手＋博弈＋淘汰）
              │                                  │
           【工程】                           【实战】
```

把四层各自钉死：

1. **「实践」退回哲学总层**：只说人与世界如何通过互动产生认识、标出边界、改写现实，不拿“实践能力”当万能标签。
2. **「工程」守住自然与系统这一半**：凡是靠技术、工具、工艺、实验装置与组织协作，在物理和资源约束里把未知探出来、把东西做出来（从建对撞机、造芯片到写软件、做化工），都归「工程」。广义工程本来就不是纯技术，而是**技术＋工具＋约束＋社会协作**的合体。
3. **「实战」收回对抗与博弈这一半**：凡是有敌手、会还手、要下注、论输赢与淘汰的地方（商业竞争、谈判、抢生态位、组织博弈），才用「实战」——让这个“战”字名副其实，不再硬塞给没有敌军的场景。
4. **「实干」作跨场景总词（口语可配「做事」）**：当需要一句话同时盖住「科学探索、工程应用、社会运作」，与「理性／理解」相对时，用**「实干（能力）」**——但按本书口径使用：**实干不是低头卖力，而是在真实约束、工具与社会条件里，扛住不确定性把事一步步往前推的能力。**

## 五、回看两类常见句子，怎么落词最稳

过一遍这一闸，刚才卡住的句子立刻顺了：

- **讲科学理解 vs 探索应用**：
  - 别只笼统说「理论与实践」，也别只说「实战」；
  - 说得最准的写法是：**理解科学理论是一回事，去探索和应用是另一回事——前者在脑子里走通概念和方程，后者要调动技术、工具和社会条件。对自然与系统，那是工程；放进资源争夺与同行竞逐的真实社会，那也是实战；合起来，都是理解之外的实干。**
- **讲个人成长（书生 vs 强人）**：
  - 偏商业、竞争、扛风险、定输赢 → 继续用**「实战能力」**，准；
  - 偏跨行业通用的“不只懂道理、真能在现实约束里推进事情” → 用**「实干能力」**或**「把事做成的能力」**，不带多余的硝烟味；
  - 偏沉淀下来的筹码与可称重的结果 → 用**「实力」**。

---

**选词速查闸**

- 问「人与世界互动的总纽带」 → **实践**
- 问「知道是什么 vs 做得到怎么做」（学习两手） → **概念 / 技能**
- 问「理解道理 vs 在真实约束里推进事情」（跨场景总称） → **理解（理性） / 实干（做事）**
- 问「靠技术、工具、工艺与组织把未知探出来、把东西做出来」 → **工程**（个人动手那截叫**实作／实操**）
- 问「有对手、会还手、要下注、有淘汰的真实博弈」 → **实战**
- 问「此时此地、信息不全的当场出手」 → **临场**
- 问「已经被成就称过重、带得走的存量筹码」 → **实力**
