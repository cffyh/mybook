# 分类不是档案柜：预测重构与体系的活性

**缘起**：Barrett 与 Miller 在 *Nature Reviews Neuroscience* 提出分类不是感觉处理的末段贴标签，而是神经系统从头到尾的预测作业——为身体的稳态／能量需求，把嘈杂世界收成此刻能套用经验的类别。成文侧早已钉：体系不是完美标本，是消化器官，砖必须代谢；知识必须重建，不能拷贝；点是面向目标的投影。本篇只把这份神经证据焊上去，不重写那些钉子。
**用途**：读「大脑如何分类」时的坐标。档案柜模型对应体系的死法；预测重构对应活性。功能层同构，机制层（皮层回路 ≠ 个人知识楼）不要僭越。

论文：Lisa Feldman Barrett & Earl K. Miller, *Categorization is ‘baked’ into the brain*, *Nat. Rev. Neurosci.* (2026), [doi:10.1038/s41583-026-01036-2](https://doi.org/10.1038/s41583-026-01036-2)。综述报道见 [Quanta](https://www.quantamagazine.org/a-new-framework-for-how-the-brain-compresses-our-noisy-world-20260824/)。解剖上反馈突触占优，作者引用如 [Markov et al.](https://onlinelibrary.wiley.com/doi/10.1002/cne.23458) 一类连接组工作；视觉皮层约九成突触走反馈，是他们论证「结构偏向预测」的一条证据，不是本篇要重审的实验。

---

## 一、档案柜，和「感觉完了再贴标签」

传统神经观点：感官进来 → 解码 → 跟记忆里的档案对上号。类别像文件，存在某个抽屉里，分类发生在处理的最后一段。

这解释不了同一声、同一触，换个场合就换类别。林子里腿被碰一下，和人行道上被碰一下，前馈信号可以很像；人已经先紧了呼吸和心跳，这一下就被收进「威胁」。类别不是等感觉齐了再贴，是预测先上场，感觉来对账。

对上书里那句假话：脑子像硬盘，拷进去、对得上就「认识了」。见 [输入是消化](../书稿%205/输入是消化，输出是生成——内外有界，进来必须建联.md)、[为什么摆到面前了，仍不是我的](../书稿%205/知识/2%20为什么摆到面前了，仍不是我的.md)。档案柜是搬运；活的分类是当场重建。

## 二、他们钉的：分类是持续的预测工具

收成作业，不重写论文：

1. **预测先于感觉的累积。** 正常环境里，反馈（预测）压着前馈（感官）。意外才冒预测误差，有时以「惊讶」进意识。
2. **类别对着身体的生存／能量需求往世界上投。** 人还没「意识到印象」，神经系统已经在为维持生理资源准备动作。情绪在 Barrett 那里也是预测性行动方案，不是固定回路里的天生标签。
3. **类别是捷径。** 能量、时间有限，用与新情境相似的过往经验，维持身体系统、并给出怎么互动的准则。
4. **不是脑的一个区在贴标签，是从头到脚的信号组织。** 边缘核心（靠近下丘脑、压缩内感受与外感受的交汇）被他们当作预测的源头之一；两个漏斗在最窄处相接，像蝴蝶结。
5. **结构偏向预测。** 内部反馈连接远多于感官前馈；视觉皮层里大量突触走反馈。不是「先看见再分类」，是「先准备类别，再让看见受它约束」。

作者的原话骨：类别可以不是动物**拥有**的一份表征，而是动物**做**的一次信号处理——预测性地约束这一团高维信号，相对某个目标或稳态事件，变得可懂、可与过去相似。分类「烤」进神经系统，是组织原则，不是智力特技。

## 三、焊到体系：活性的神经显影

[要体系，又嫌体系](../书稿%205/知识/3%20要体系，又嫌体系.md) 第六节钉过：第一问不在完美，在活性——代谢、吸收外部、产出判断与推测。追求正确／全面／深刻，走向封闭，当圣经。

Barrett–Miller 的档案柜，就是那条歧途在感知层的样子：类别封成文件，感觉只负责对号入座。他们的替代模型，和「器官还在工作」同骨：

| 神经侧 | 书里体系侧 |
|---|---|
| 类别每时每刻按感官＋记忆＋身体需求重构 | 砖必须代谢；切片是成果，下一刻又回到器官 |
| 预测主导，感觉来校准 | 体系暗处无处不在；临场很少单独当第一下，乱了／失灵了才显形 |
| 同一前馈，场合不同则类别不同 | 每一局都是新的；不可套用，必须沿用。见 [成熟与前沿](../书稿%205/总论/1.21%20成熟与前沿——不可套用，必须沿用.md) |
| 预测误差／惊讶 | 常识、模仿、经验失灵 → 实事求是找事实、站事实。见 [临场](../书稿%205/总论/1.2%20临场——时空、差异与迭代.md) |
| 类别为能量与时间省事 | 以有限应对无限；点是有损投影 |
| 对着身体需求往世界上投射类别 | 对着目标投影；图不是山，「以为」的那套世界真相 |
| 分类是做，不是拥有一份永真档案 | 手段和过程是消化器官，不是盖完的楼 |

故：体系威力大，正因为大脑本来就靠分类／预测才能活——没有坐标，嘈杂进不来、经验套不上。体系容易歧途，也正因为预测太省事：档案柜一焊死，新信号只能在旧抽屉里对号，林子里的触碰还按人行道来分。活性要的是：预测仍在（沿用成熟），误差进得来（代谢砖），场合一换能当场再投一版类别（不可套用）。

个人体系「对着你的目标投影」「相对世界极小」，和「类别按此刻稳态需求压缩世界」，是同一刀的两层显影。一层是认知楼，一层是神经系统。功能上像：都是有内部目标的系统，把无限收成此刻能动手的有限。机制上不是一回事——别写成「所以知识体系长在边缘皮层」。见 [同构判据](../书稿%205/总论/2.2%20同构判据——功能·机制·结构，两旋钮与四问.md)。

## 四、再挂几颗已有的钉

**点。** 同一张网，换目标投出不同的点。同一团感官，换场合投出不同的类别。轴都是需求／目的／稳态，不是材料自己长出标签。见 [点是面向目标的投影](../书稿%205/点/点是面向目标的投影——不是知识的内禀属性.md)。

**记忆。** 记得牢的不是印象原件，是能再生成。预测用的是压缩过的过去，不是档案复印件。见 [记忆的两根轴](../书稿%205/记忆的两根轴——一钮·两标·四面·两肢.md)。

**在例子中学习。** 感知 → 仿真预测 → 偏差修正。预测编码在学习作业上就是这一圈；Barrett–Miller 补的是：连「看见是什么」这一步，也已经在预测里。

**控制论。** 目标状态、偏差、调节。预测误差是偏差的神经说法；控制的对象仍是偏差，不是把世界复印进脑子。见 [控制论的奠基](../书稿%205/走向真实的交易/控制论的奠基-行为、目的与目的论.md)。

**关心与需求。** 心还没命名缺口，身体已经在为能量和威胁做准备——林中那一下。关心是发现层的闸；预测可以比命名更早。不要把内感受预测写成「关心生出需求」。见 [关心](../书稿%205/走向真实的交易/2.4%20关心——从注意到玄之又玄的词.md)。

**无用之用。** 反馈突触那么密，预测一直在跑，人却很少觉得自己「在分类」。和体系一样：无处不在，又很少单独当第一下。见 [从方法到实力](../书稿%205/总论/1%20从方法到实力——无用之用与生态位上的历史积累.md)、[知识体系](../书稿%205/总论/1.3%20知识体系——无用之用与可生长的坐标.md)。

## 五、过闸

- 这篇是综述框架，不是新的单点实验「证明了体系哲学」。焊的是读法，不是把论文当圣经。
- 感知／情绪类别 ≠ 公共知识体系。一个是神经系统的压缩，一个是可传的符号结晶。同构停在「预测性重建、按目标投射、档案柜必死」。
- 「预测塑造分类」不是「怎么感觉都行」。误差还在；失灵还要退回事实。活性包含被世界打脸，不包含封闭循环。
- 边缘核心、下丘脑、九成反馈突触，是他们论证结构偏向预测的材料；本篇不代做神经解剖。

人不被嘈杂淹死，靠的不是把世界复印进一只完美档案柜——是不停按身体和目标，把世界收成此刻能动手的类别。体系要活，也是这一句。
