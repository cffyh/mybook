# 弦网凝聚与量子比特海：两层不要收成一层

**缘起**：胶球综述与 [胶球三层读法](胶球三层读法：证实、中间层、哲学何时上场.md) 已钉：胶球验证 QCD，推不出量子比特海，也推不出 OSR。书稿1 [信息即实在](../书稿1/05-2-信息即实在.md) 写过量子比特海，并标清那是猜想。本篇补一刀科普最容易糊的：**2+1 维弦网凝聚**是凝聚态内部成熟工具；**3+1 维量子比特海**是把演生思想外推到宇宙真空的宏大假说。两层不要收成一句「文小刚已经证明真空是量子比特」。
**用途**：读文小刚、读拓扑序、读「胶球支持量子比特海」时的坐标。工具和本体猜想分开。

---

## 一、先劈开

| | **2+1 维弦网（Levin–Wen）** | **3+1 维量子比特海** |
|---|---|---|
| 研究对象 | 二维材料、超导芯片、里德堡原子——真空**之上**的多体系统 | 真空**本身**是纠缠量子比特海 |
| 属于 | 凝聚态物理；拓扑序的核心工具 | 粒子物理／量子引力猜想；**不是**凝聚态课题 |
| 目标 | 拓扑序、任意子、演生规范场；服务拓扑量子计算 | 演生标准模型粒子、杨–米尔斯、最好再演生引力 |
| 成熟度 | 理论成熟；量子模拟可复现；天然固体尚未干净实现非阿贝尔弦网 | 启发性假说；无完整可工作模型；无直接实验证据 |
| 与胶球 | 低能有效层面可以**兼容**胶球图像 | 地面高能实验（含 BESIII X(2370)）**不能**证实／证伪 |

鱼缸比喻：弦网凝聚是在鱼缸里研究水波与漩涡，工具好用。量子比特海进一步猜想——**整个宇宙是一口大鱼缸，夸克胶子电子都是漩涡**。鱼缸内成功，推不出宇宙本身就是鱼缸。

More is different 在凝聚态内部是事实：大量粒子会涌现新规律。外推「标准模型粒子一定也是真空的演生物」——A 域大量现象服从 X，推不出 B 域必须服从 X。

很多人做的是 2D 拓扑序、融合范畴、张量网络，**悬置**宇宙本体。用工具 ≠ 接受假说。

## 二、数学：近十五年真正长出来的砖

这些砖主要垫在 **2+1 维**。不要写成「量子比特海已被数学证明」。

1. **融合范畴取代群论，成为拓扑序的语言。** 朗道相变靠群论＋对称性破缺；拓扑序靠球面融合范畴——任意子的融合、编织、F／R 符号。把任意融合范畴喂进弦网，直接输出任意子谱。高阶范畴往 3+1D、分形子推：弦网变成弦–膜网。群上同调与 SPT 打通，物态有了「周期表」。范畴学在这里是**已证实可站上去的技术**，同构见胶球读法第一节：证明带出的是技术，不是感想。

2. **张量网络把弦网变成可算的。** PEPS 精确表示基态；MERA 做纠缠重整化。拓扑纠缠熵（负的）是可计算判据，量子模拟直接测它来标定弦网态。

3. **玻色格子可以演生费米子。** 老直觉：玻色拼玻色。文小刚团队证明：有弦网长程纠缠的玻色格点模型，会自动涌现费米子，且费米子必然带演生规范荷。这是量子比特海构想最硬的数学支点——底层只有玻色量子比特，原则上可以长出电子／夸克和光子／胶子。

**局限钉死：该证明主要严格在 2+1 维；3+1 维没有完整闭环。** 支点不等于大厦。

## 三、理论：成熟的一块，未完成的一块

**A. 成熟：二维弦网凝聚（凝聚态主流）**

Levin–Wen 哈密顿局部对易，精确基态即弦网凝聚；基态简并由流形拓扑决定；弦端点是任意子；弦的集体涨落演生规范场（U(1)、Z₂…）；光子相当于弦网密度波。Fibonacci 弦网的非阿贝尔任意子，编织可做通用拓扑量子计算。这部分不是猜想，是标准工具箱。

**B. 未完成：3+1 维量子比特海（真空＝弦网液体）**

愿景：三维格点上大量纠缠量子比特；特定长程纠缠的液体，低能同时给出麦克斯韦、杨–米尔斯、狄拉克费米子——标准模型粒子全是集体激发。

已有的阶段性进展：

- 概念上劈开短程纠缠／长程纠缠。It from bit 旧思想失败，根子是只用短程纠缠；只有长程纠缠才能同时涌现规范场＋费米子。05-2 已写过这把钥匙。
- 若干 3+1D 格点模型能演生 U(1)（类光子）。

**核心目标没有完成。** 完整演生非阿贝尔杨–米尔斯（QCD 胶子）＋手征狄拉克费米子，至今没有严格可解格点模型。最大卡点：**手征费米子**（左右不对称，标准模型核心）；格点上从玻色底层演生它，数学极难，文小刚本人多次公开指出。引力作为纠缠演生：几乎只有概念，没有具体模型导出爱因斯坦方程。

客观一句：2+1D 非常成功；3+1D 有漂亮局部结果，完整复刻标准模型属于高度启发性猜想，不是成熟理论。

## 四、实验：全是模拟模型，不是检验真空

所有现有实验都是**在人造量子系统里模拟 2 维弦网模型**。不是证明我们的真空是量子比特海。

| 类 | 做到哪 | 不是什么 |
|---|---|---|
| 超导量子模拟（2024–2025 最硬） | 浙大–清华 27 比特芯片：Fibonacci 弦网基态、非阿贝尔任意子编织，拓扑纠缠熵与预言吻合；2025 动态制备与通用门原理验证；Toric code／Z₂ 已很熟 | 不是自然界材料里发现 Fibonacci 液体，更不是真空检验 |
| 固体材料 | Kitaev 候选（α-RuCl₃ 等）有分数化激发迹象 | 杂质、温度、无序破坏长程拓扑序；干净非阿贝尔弦网固体尚未确定实现 |
| 宇宙真空直接检验 | 理论上或有洛伦兹微小破缺、极端宇宙线信号 | 能标近普朗克 $10^{19}$ GeV，加速器差十几个数量级；**无可行直接方案** |

故：量子比特海作为宇宙底层本体，短期既不能证实也不能证伪。只能在低维凝聚态里模拟它的**模型**。模拟成功＝机制可造，≠ 宇宙采用了这套机制。05-2 对 2024 实验已经写过这句，本篇只加分层。

## 五、凝聚态在干什么（弦网落在哪一块）

凝聚态研究大量粒子聚在一起的集体现象：强关联、量子多体、演生、拓扑、量子材料、非平衡。哲学是 More is different——单粒子定律已知，多了会涌现推不出来的新规律。

四大块，弦网只占其中一格：

1. **强关联**：高温超导机理未定；量子自旋液体；莫特相变。弦网／自旋液体与「掺杂自旋液体或出高温超导」有猜想关联，不是已证。
2. **拓扑量子物态**：SPT（拓扑绝缘体、外尔半金属，已有材料与器件潜力）≠ 拓扑序（长程纠缠；弦网在这里）。未解决：3+1D 拓扑序与分形子的分类／材料；非阿贝尔任意子的固体实现；长程纠缠的实验探针。
3. **量子模拟**：可控人造系统模拟解析／经典算不动的多体模型。已模拟弦网与任意子编织；NISQ 噪声是瓶颈。
4. **非平衡**：Floquet、时间晶体、MBL——尚未有成熟普适范式。

应用侧：拓扑器件、拓扑量子计算硬件、莫尔超晶格。弦网是拓扑序分支最重要的理论工具之一，**不是全部**。

**两层演生不要糊：**

- 凝聚态内部：准粒子（声子、自旋子、任意子、演生规范场）真实可测，演生是事实。弦网是这块最漂亮的范本。
- 外推到真空：启发性猜想，不是实验事实。

## 六、胶球、OSR、标准模型：三句仍不要收成一句

1. **X(2370) 胶球**是标准模型／QCD 框架内的高能实验，研究真空之上的粒子。可以在弦网低能有效描述里被解释为某种集体激发，**不能当量子比特海的证据**。没有任何地面高能实验可以直接证实／证伪 3+1D 量子比特海。
2. **OSR** 是哲学立场，不做实验预言。弦网是一套**具体物理模型**，用来走演生论。OSR：实在是关系结构。弦网／量子比特海：实在是底层纠缠量子比特，粒子是涌现——这是更强的、给出具体自由度的物理假说，**不等同** OSR。可以例证 OSR，不能证明 OSR。
3. **标准模型仍是中间层。** 2+1D 弦网在凝聚态内部也是中间层：上接「物态可以有更深的纠缠分类」，下接这一块芯片、这一次编织、这一种任意子谱。3+1D 量子比特海接不上 2.4 GeV 这一局，也接不上当下的加速器清单。更深不等于此刻更有用。见胶球读法第二节。

哲学是否上场，仍只问有没有进入那个时代的互动。2D 弦网已经进入：它改了拓扑量子计算和量子模拟怎么出手。3D 真空假说还没有——没有改方程、没有改加速器、没有可做的真空实验。见胶球读法第三节。

## 七、未解决（该方向公开痛点）

1. 3+1 维格点上，从纯玻色自由度严格演生**手征费米子**——没有完整构造。
2. 演生非阿贝尔杨–米尔斯（QCD）的完整弦网格点模型缺失。
3. 从弦网导出引力／广义相对论：几乎无具体模型。
4. 没有可行的直接实验检验「宇宙真空是量子比特海」。
