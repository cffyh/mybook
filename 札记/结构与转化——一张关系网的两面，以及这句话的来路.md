# 结构与转化——一张关系网的两面，以及这句话的来路

**缘起**：全书大纲第一卷写「本体论：世界是结构，不是实体」，第二卷写「动力学：世界的本质是转化」。既说是结构，又说是转化，两句都在抢「世界是什么」。导论还另有一句：相互作用是宇宙间最原始的创造力。三个词都被叫成了第一。本篇把排位理清，改掉链上一处用词颠倒，并交代这句话在哲学史上的来路，以及今天能说得更准的地方。

**用途**：给全书的本体论和动力学定一个不打架的说法。导论、大纲、总纲、[变化与转化](../书稿%205/总论/2.0%20变化与转化——看见的多样，和有源头的那一条链.md) 已按本篇统一。

---

## 一、冲突在哪

按导论第二节的读法，两句本不冲突。那一节说，任何一个「现在」都是变化洪流中暂时凝结的结构，所有的转化都在一个具体的结构网络中展开。结构是名词，转化是动词，说的是同一张关系网的两面。

冲突出在字面上，有三处。

**第一处，转化修饰的是状态。** 原来的链写作「相互作用 → 结构变化 → 状态转化」。转化在最后一环，主语是状态。可导论又说状态是结构的影子。把「状态转化」立为世界的本质，等于把影子的移动立成了本质，和「结构比实体更根本」正面相撞。

**第二处，用词和《变化与转化》的定义颠倒。** 那一篇把两个词分开：变化是看见的多样，在状态那一层；转化是有源头、有相互作用、有结构改变、有守恒的那一条深链。照这个分法，深层的结构该配「转化」，表层的状态该配「变化」。原链正好反过来。

**第三处，三个第一。** 本体论卷说结构第一，动力学卷说转化第一，导论说相互作用最原始。读者不知道哪一个是地基。

## 二、怎么改

链改成：

> **相互作用 → 结构转化 → 状态变化**

转化的主语从状态换成结构。本体论说「世界是关系结构」，动力学说「结构在相互作用中转化」，两卷主语相同，不再抢第一。状态仍是影子，影子的移动叫变化。

三个词的排位：

> **相互作用是底；结构是相互作用的凝结，转化是相互作用的展开；守恒是结构在转化中不变的那一面。**

结构不是摆在那里的静物，是无数次相互作用沉淀下来的稳定格局。转化不是另一种东西，是这些格局在新的相互作用下重组。守恒不必单立一根柱子，它是结构穿过转化仍保留的那一部分。

大纲两卷因此改为：第一卷「本体论：世界是关系结构，不是孤立实体」，第二卷「动力学：结构在相互作用中转化」。「本质」一词不再用，理由见 [慎用「本质」](../关键文章/逻辑/慎用「本质」——没有终极的底，只有对准问题的结构.md)。

## 三、转化比变化、比过程多说了什么

转化留作动力学和方法论的核心，因为它确实多说了几样：

- **比变化多**：有源头，有守恒，有结构上的机制。《变化与转化》已经写清。
- **比过程多**：过程只是时间上的一串事件，可以是平滑的。转化是「由此成为彼」，带着跨过门槛、换了一种样子的意思。冰化成水，量变到质变。
- **条件**：转化总在一定条件下发生。找到条件，就找到了下手处。以小控大靠的就是这一点。
- **对立面互转**：祸福相倚，矛盾双方在一定条件下相互转化。中文「转化」自带这层辩证意味。
- **可追溯**：要交出那一条链，不能事后编。这是转化在作业层的纪律，见 [三句内核](../三句内核——认一个系统、世界怎么动、人凭什么下手.md)。

所以，它撑得起动力学这一层，撑得起方法；撑不起整座大厦的地基。

## 四、为什么它不能单独当地基

1. **它是二阶概念。** 转化总是某种东西的转化。先得有结构、有守恒量、有推动它的相互作用，才说得出转化了什么。要先借三样东西才立得起来，就不是第一。
2. **大纲第一卷自己写着「对称性与作用量才是底层」。** 按现代物理，支配变化的是不变的结构。这等于承认结构比转化更深一层。
3. **作为口号，它不排除任何东西。** 「一切都在转化」永远对，所以什么也没解释。它的信息量全在「要交出链」那条纪律里，不在口号本身。
4. **它和导论自己的第四节相抵。** 第四节说没有绝对本质，第一节却对「世界」这个最大的范围下了本质判断。

## 五、来路：这句话大体是重述

「世界的本质是转化」并不新。最接近的前人是恩格斯和普里戈金，几乎原句可以对上。

- **赫拉克利特**：万物皆流；永恒的活火「按尺度燃烧，按尺度熄灭」；战争是万物之父；上升的路和下降的路是同一条。转化、守恒（尺度）、相互作用（斗争）、对立面互转，四样已经全有。
- **《易》**：易一名而含三义，变易、不易、易简。几乎就是本书「转化、守恒、相似相异」三母题的古本。
- **老子**：反者道之动；祸兮福之所倚。对立面转化。
- **佛教缘起说**：诸法因缘生，无自性。没有实体，只有关系与条件。
- **黑格尔**：变易是存在与无的统一；量变质变。转化的辩证形态。
- **恩格斯**：世界不是既成事物的集合体，而是过程的集合体；又把能量守恒与转化定律列为三大发现之一。导论第一节几乎是前一句的改写，「转化加守恒」也是恩格斯的组合。
- **普里戈金**：《从存在到演化》；耗散结构靠流动维持。导论原句「不是存在，而是转化」就是这个书名。

还要看到，「不是存在，而是转化」是在一场两千多年的老争论里选了一边。一边是巴门尼德，存在不变；一边是赫拉克利特，万物流变。现代物理并没有替哪一边判赢。相对论的块状宇宙偏向巴门尼德，爱因斯坦说过过去、现在、未来的区分只是一种顽固的幻觉；热力学的时间箭头才偏向赫拉克利特。所以「转化为第一」在物理上是有争议的立场，不能当作科学定论来写。

本书在这条老路上真正自己的东西，不是口号，是作业：转化要交出链；事后必然性是表面相似的时间版；守恒给「唯有变」立章法。

## 六、今天能说得更准的地方

1. **结构实在论已经把动力学收进了结构。** 拉迪曼、弗伦奇一路的本体结构实在论里，结构本来就包括支配变化的规律与对称。按这个说法，「本体论讲结构、动力学讲转化」的分家并不必要：转化是结构自身规定的展开方式。见 [范畴是结构的格](范畴是结构的格——康德、范畴论与结构实在.md)、[哲学能干什么](哲学能干什么：OSR与互动论的预言和指导.md)。
2. **诺特定理：守恒来自对称。** 时间平移不变，推出能量守恒；空间平移不变，推出动量守恒。三句内核说「守恒是相似相异沿时间轴的用法」，这正是诺特定理的通俗版。守恒于是归到结构名下，是结构在转化中不变的那一面。
3. **动力系统与相变，给变化和转化一条本体上的界线。** 状态是状态空间里的一个点；结构是决定状态往哪走的那片地形，也就是规律和吸引子。在同一片地形里移动，是变化；地形本身改了，状态跳到一个新的吸引子上，是转化。水结冰，物理上叫对称性破缺。这比「交不交得出链」的认识论标准更硬，也让「状态是结构的影子」有了精确含义。
4. **关系量子力学。** 罗韦利说，世界由事件和相互作用构成，不由东西构成；物体的属性只在相互作用中才有定义。这是「相互作用是底」的现代版本，比「转化第一」更站得住。
5. **有效场论。** 每一层描述都在自己的尺度上有效，不依赖更深层的细节。这是导论「本质永远是更深一层本质的现象」的精确版：没有终极底层，但每一层都有自己可靠的结构。

## 七、要点

1. **结构与转化不冲突，是同一张关系网的名词面和动词面。**
2. **链改为相互作用 → 结构转化 → 状态变化。** 转化的主语是结构；状态是影子，影子的移动叫变化。
3. **排位：相互作用是底；结构是它的凝结，转化是它的展开；守恒是结构在转化中不变的那一面。**
4. **转化撑得起动力学和方法，撑不起地基。** 它是二阶概念，作为口号不排除任何东西。
5. **口号是重述，作业是自己的。** 赫拉克利特、《易》、恩格斯、普里戈金都说过；本书的贡献在「要交出链」那套纪律。
6. **今天更准的说法**：结构含规律与对称；守恒来自对称；变化是同一地形里的移动，转化是地形本身改了。
