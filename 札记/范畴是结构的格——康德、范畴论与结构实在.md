# 范畴是结构的格——康德、范畴论与结构实在

**缘起**：结构是最底层，但结构太泛。康德的先天范畴、数学的范畴论、本体结构实在论（OSR），名字挨着，容易收成一层。本篇不重写 [哲学能干什么](哲学能干什么：OSR与互动论的预言和指导.md) 的杠杆配置，不重写 [结构之眼](../书稿1/04-2-结构之眼.md) 的代数史，不重证 OSR。只收三刀：三问分开；数学范畴论的内涵，是把「结构先于实体」做成可算的文法；作为指导思想，对错不在内部自证，价值从外部的互动与边界读。
**用途**：给「结构／范畴／OSR」一把分层尺，并从作用读它们。康德与数学的范畴不是同一种东西；从另外一个角度，两者都是以有限格无限。胶球推不出 OSR，见 [胶球三层读法](胶球三层读法：证实、中间层、哲学何时上场.md)。功能同构不是机制同构，见 [同构判据](../书稿%205/总论/2.2%20同构判据——功能·机制·结构，两旋钮与四问.md)。

## 一、三问，不是三个名字

| | 康德的先天范畴 | 数学的范畴论 | 结构实在 |
|---|---|---|---|
| 问的是 | 认识何以可能 | 结构何以被统一地写、比、搬 | 世界凭什么可被把握 |
| 范畴是 | 主体这边的先天骨架 | 对象 + 态射这套语法 | 不是它的词 |
| 结构落在哪 | 范畴作用之后，现象才有秩序 | 数学研究的对象（群、环、空间……） | 世界本身 |

康德十二范畴——量、质、关系、模态——是有限心灵收无限杂多的格。没有这套格，眼前只是一堆感觉，连「一个对象」都立不起来。他那次综合说：不是思维去符合对象，是对象来符合思维；眼前的自然，是被格整理过的现象。知识因此既能贴住经验，又有普遍必然。见 [数学精神与科学方法](../书稿%205/数学精神与科学方法.md)。

数学范畴论是艾伦伯格与麦克莱恩 1945 年借了这个词。借的是「一类可归在一起的东西」，不是康德那张表。它做的事更窄、更硬：把群、环、空间这些结构，一律写成「对象 + 保持结构的箭头」。对象是什么，先不问；先问箭头怎么合成、什么叫相同。米田引理把这句推到底：一个对象，就是它与万物的映射关系。关系优先于实体，在这里不是口号，是一条可证的引理。

结构实在是本体主张：世界底下是关系与结构，没有先于结构的个体。人能以小控大，因为世界以小成大。根据在世界，不在人的野心。见 [从小与大到以小控大](../从小与大到以小控大——底层视角如何闭环.md)。

名字同源，问题不同。这是第一刀。

## 二、结构太泛，范畴是格

「数学研究的是结构」，布尔巴基那句是对的，也是空的。晶体、群、句法、科层、康德说的综合统一，都能叫结构。底是它，但底太宽，下手处没有。

范畴是结构的格——把一类结构写成可对照、可搬运的关系网。

康德那边，格在认识：杂多不能直接抓，先天范畴把它们收成可判断的对象。数学那边，格在运算：指定哪一类对象、哪一类箭头。有了这张格，才能问两个结构是否同构、一层结构能否嵌进另一层、哪条性质沿箭头保持。函子是搬运，自然变换是比较搬运，伴随是最经济的添结构与忘结构。

两边都是以有限格无限。对象不是现成的，是格把它收出来的。康德收的是可经验的对象，数学收的是可搬运的结构。一边成就认识，一边成就运算。见 [以有限应对无限](../书稿%205/走向真实的交易/上篇-人怎么做/以有限应对无限-人类把握世界的方式.md)。

同的不是表上的格子，是这一手：**先立格，后推理可走。** 康德走的是判断能普遍；范畴论走的是证明能搬运。功能同构，机制不同。

差必须留着。康德的格是先天的、主体的、基本上是一张表。它不证明韦伊猜想，也不给镜像对称提供共同语言。数学的格是后做的、可换的、而且必须可算。换一张网——集合、群、层、谱——同一位置上的积与核还在。它不回答休谟。

若把康德收进范畴论，十二格变成对象与态射，麦克莱恩只是借词。若把范畴论收进康德，拓扑斯变成先天形式，德利涅那一笔就变成先验演绎。两边都滑。

结构实在也不要塞进任何一边。它是导向：世界咬得住，因为底下是关系。范畴论不证明它，只是一旦你接受「先问关系」，数学已经备好了能算的格。康德也不证明它：他停在现象，物自体在门外。

中间仍是 [逻辑](../书稿%205/走向真实的交易/上篇-人怎么做/逻辑-世界的自在之理与思维的同构之路.md) 那座桥：认识逻辑逼近自在之理。没有「万有引力」这个范畴，苹果照样落地。世界有自在之理，范畴是编码的工具，不是世界的立法。

## 三、数学范畴论的内涵：做成可算的文法

一个范畴要有四样：对象，态射，合成，恒等。同构从此有了干净的定义——存在一支箭头，能找到逆箭头，来回走都回到恒等。「本质上是同一个」不再靠直觉，靠箭头。

集合范畴里，箭头是函数。群范畴里，箭头是保运算的同态——元素全换、规则还在，群还在。拓扑空间范畴里，箭头是连续映射；甜甜圈和咖啡杯同构，因为存在双向连续、互为逆的箭头。偏序集也是范畴：当且仅当 $a\le b$ 时有一支箭头。一个群本身也是范畴：单对象，箭头是元素，合成是乘法。群论被收进来，不是被取消，是被写成「单对象、箭头可逆」的特例。

真正发力的不是这张清单，是函子与自然变换。函子在范畴之间搬运，合成与恒等一起被保住。遗忘函子把群忘掉运算，只留下集合；自由函子反过来最经济地添上结构。这一对是伴随。同调、上同调也是函子：空间送到交换群，连续映射送到群同态。「洞的数目」不再是每个空间上临时数的，而是沿箭头自动走的不变量。

内涵不在定义，在它已经做成的事。四处都是同一句文法：

**同一格里的同一位置。** 极限、余极限、伴随、米田，不绑在群或空间上。证明一次，集合、群、层、模、谱上一齐有。以前每个领域发明自己的积、和、核、商；范畴论指出它们是同一格里的同一位置。

**新语言让问题变成推论。** 格罗滕迪克用层范畴、拓扑斯，重写「什么叫覆盖」，造出 étale 上同调。德利涅补完最后一块，韦伊猜想落地。费马大定理后头的模空间、算术几何，走的是同一条路。为了一个计数问题，先造一套新语言，问题在新语言里变成推论。见 [代数几何的革命](../关键文章/学科/格罗滕迪克-收获与播种/03-代数几何的革命.md)。

**空间可以没有预先的点。** 拓扑斯比概形更深：只要有「覆盖」这套关系，以及把局部粘成整体的层。点不必预先有。这是范畴论把「结构先于实体」做成可算语法的一次。

**各科能说同一种话。** 导出范畴把复形上的同调收成一个范畴，代数几何、表示论、镜像对称从此对得上。融合范畴写任意子的融合与编织：对象是粒子类型，箭头是过程。弦网模型里，输入一个融合范畴 $\mathcal{C}$，输出的拓扑序是它的 Drinfeld 中心。不是物理证明了范畴论，是哈密顿实现把抽象范畴变成可画、可算、可喂进芯片的对象。见 [弦网凝聚：数学组织、对照圈量子引力、干活定位](弦网凝聚：数学组织、对照圈量子引力、干活定位.md)。

一句话：结构先于实体，被做成了可算的文法。没有这套文法，结构只是「底下有关系」；有了它，五次方程与对称、甜甜圈与咖啡杯、素数与几何点、微分方程与拓扑洞，才能在同一张箭头网上相认。书稿1《结构之眼》那三级台阶——符号化、结构主义、范畴论的统一——就是这句话的史。

## 四、对错不在内部

OSR 不改方程，不报下一个粒子。胶球来了，它不必改口；胶球不来，它也不必改口。内部还可以继续吵：没有关系者的关系能否说圆、温和版还是激进版、结构之下有没有剩余的「东西」。这些争得再细，没有一种外部回应能把它判死。空，空在没有对手——世界不来应这一局。

范畴论若也去争「数学的本体是不是对象加态射」，同样空。布尔巴基说数学研究结构，已经太泛；再升成「世界就是范畴」，只是换了一张更大的标语。麦克莱恩没有证明实体不存在，他给了一套写法。

康德那张十二格也一样。没有实验能证实或证伪「因果是先天范畴」。它的意义从来不在法庭，在：有了这套格，经验才能被判断。

三件东西，内部自洽都不够当证据。证据在外面。

## 五、指导思想打开天地；价值从互动与边界读

OSR 作为指导思想，强制的只有一句：别把力气押在「最小那块东西」上，押在哪些结构能被写出、算清、拿来互动。范畴论是这句的可算文法。杠杆配在哪一层，见 [哲学能干什么](哲学能干什么：OSR与互动论的预言和指导.md)——本篇不重排那张表。

打开的天地，都是外部已经应过的。不为「点是否更根本」立案，而为了一个计数问题换地基，算术几何成了大陆。不为「粒子是不是实体」立法，而为拓扑序换语言，2+1 维这边世界已经在应。不为「大模型是不是本体」站队，而承认关系结构一旦便宜可操作，时代的互动已经改到那一层。

格罗滕迪克那句：为了一个问题，先造一套新语言，问题在新语言里变成推论。这就是指导思想的作用——**涨海，不是审案。** 海涨起来，岸上原来过不去的船过去了。过去了，就是它的价值。没有过去，再自洽也只是 yoga——他自己把尚未严格定义、却已能带路的感觉，叫这个名字。

《三句内核》里有一句还没被用到这个题目上：**内那一路永远不是真的打开，是靠外那两路反推出来的模型。** 认识一个系统：边界划界，互动跨界，结构化组织界内。OSR 与范畴正在「结构化」这一格。要读它们，不能拆开内脏看「结构是不是真的」，要走外两路。见 [边界与互动](../书稿%205/走向真实的交易/边界与互动-认识系统的两种法门.md)、[三句内核](../三句内核——认一个系统、世界怎么动、人凭什么下手.md)。

**互动：它有没有改变交手的方式。** 人与世界的内核不是理解。机械论进了工程，一个时代用机器交手；经验论进了实验室，一个时代用可控实验交手。OSR 加范畴论进了场，交手变成：写关系、搬箭头、改覆盖、把结构做成可测的对象。德利涅补上那一块，是世界在应；芯片上编一次任意子，是世界在应；镜像对称能用导出范畴对译，是两个领域在应。应了，指导思想就从暗处走到台前。停在「我们主张结构更根本」，它仍是备而不用的器具。

**边界：它在哪里不行，轮廓才清楚。** 「不行」的信息量大于「行」。OSR 的边界已经硬：指导不了该开哪条衰变道，那是 QCD 的中间层；强制不了「真空必须是比特海」那一跳；dead time 接不回来的本体实验，它若去抢，层级拧了。范畴论的边界同样硬：不是每个计算都值得先画一张箭头图；直觉仍是根，结构是干，文法不能冒充根，见 [数学精神与科学方法](../书稿%205/数学精神与科学方法.md)；格太粗，结构仍泛，格太细，yoga 还不成形。

探清这些「不行」，不是驳倒它们，是画出职务。中间层该做中间层的活；指导思想只做导向：力气压在哪一层，对象从哪一种关系里收出来。

## 六、职务

| 假 | 真 |
|---|---|
| 康德发明了范畴论 | 借词，不是一张表 |
| 范畴论证明了结构实在 | 文法不是地契 |
| 世界的本体被证明是结构 | 作为指导思想，它打开了「押结构、不押实体」这片地 |
| 内部自洽所以对 | 价值看这片地上长出了哪些可互动的对象，看它在哪一层必须停手 |
| 哲学不报粒子，所以无用 | 预言的是杠杆；指导第一下打在哪一层，已经是一种上场 |

康德仍在认识那一端：以有限格无限，让经验可判断。数学范畴在运算那一端：以有限格无限，让结构可搬。OSR 在导向那一端：告诉你别往实体清单里挖。三问不同。从作用看，却同在这一手——先立格，再出去交手；对错不在格里自证，在外部的应与不行。
