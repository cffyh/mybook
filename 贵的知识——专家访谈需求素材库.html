一、结论：知识的定价规则

这批素材是专家访谈网络上买方机构（二级市场基金、一级投资、大厂战略部、咨询公司）真金白银在买的问题。它们证明一件事：公开信息已被充分定价，真正有市场价格的知识，是"在场者"头脑里那些具体的、带口径的、新鲜的事实——一个分成比例、一条产线的良率、一次开城的决策流程。分析、观点、框架反而不值钱，因为买方自己有的是分析师。

1. 市场在押注什么（从"问什么"看）

  • AI 的问题全部换挡到"变现"：没人问技术行不行，问的是 AI 搜索的广告收入和 PV、AIGC 的客单价与复购率、AI 音乐的收入分成、图像生成单张成本两年降了几倍。技术被默认成立，定价的是商业化速度和成本曲线。
  • 自动驾驶进入"算账期"：问 Waymo 和小马的不是感知算法，而是 MPI、单车天收入、UE 是否打正、第 7 代车降本幅度、租售比例——从故事定价切换到报表定价。
  • 汽车产业链被扫描到毛细血管：固态电池配方、精密压铸、下线检测设备的经销商激励、外饰改装件出货量、嵌塑端子框架。主战场信息差抹平后，钱在往二阶、三阶供应链找错误定价。
  • 广告预算流向被当作经济晴雨表：反复出现"26Q1 各平台预算绝对值和增速"，拆到品牌/达人/效果、拆到字节/腾讯/红书/OTV——用广告主的钱包投票，前瞻平台公司收入。
  • 出海是默认命题：扫地机在美国的消费者心智、泰国汽车媒体的投放价格、越南汽配竞争、印尼巴淡岛的水电。
  • 注意力地图：滴滴系被问了十余次（网约车、两轮 SaaS、快送、货运、租车、商旅、广告预算、自动驾驶 GR、境外客服……），被反复问的公司和被反复要的指标（UE、分成比例、预算流向），标出了资本认为不确定性最大、赔率最高的地方。

2. 专业的知识获取长什么样（从"怎么问"看）

  • 验证前置（test question）：几乎每单都有 testq，且明确要求"知道确切数据，而不是'能聊但实际上不知道'"——先用可证伪的小问题甄别信源，再投入访谈成本。证据分级做成了流程。
  • 口径意识："明星预算 = 商单 + 投广 + IP 营销 + 单独代言，内部口径不一样也 OK，但需要说明口径"；"OTV 特指爱优腾芒"；同比对照期精确到日且对齐农历（2026.2.15-2.23 vs 2025.1.27-2.4）。没有口径的数字不是知识。
  • 拆到可回答的颗粒度：不问"春节做得怎么样"，问完单 GMV、续租占比、列表页 UV、支付转化率、支付后取消率、商责取消前三大原因。宽问题换来套话，窄问题换来事实。
  • 问激励结构而非战略表态：麦当劳问联盟开发与前线开发的奖金分成比例；微软问"销售 KPI 里有没有 Token 售卖导向指标、占比多少"。看一个组织怎么分钱怎么考核，比听战略宣讲硬。
  • 三角验证：同一标的从供应商、客户、竞对多角度找人（iwis 明确"优先从下游客户找专家"）；小安 SaaS 要拿哈啰、青桔、泰比特横比。单一信源不构成结论。
  • 每个数字后面必须跟"为什么"："增速变化的原因是什么"出现几十次。要的不是数据点，是机制——只有机制能外推。
  • 精度与用途匹配：Lefant 单写明"可以接受概数/区间，不需要精确值"。知道何时不需要精确，与知道何时必须精确，是同一种能力。
  • 信息有半衰期："时间 ASAP""求求今明时间""离职须三个月内"——过期的内部信息退化成公开信息，而公开信息免费。

3. example 文件夹补充的四个维度

  • 买方要的是能直接进模型的参数：《单店营利性测算》是搭好的 UE 模型等专家填参数（单位平米租金、底薪、去提成毛利、装修投入→自动算盈亏平衡与回本销量）；《Data Template》要分品牌分年份的 GMV、转化率、退货率、投流 ROI、A1/A3/A5 人群。专家知识的最高形态是"能填满一张别人搭好的表"。
  • Test 问题钓的是"伤疤"不是知识点：境外客服单问"建设历程里踩过最大的坑（技术选型错误、供应商跑路、数据迁移灾难）""哪些问题你们故意不让智能客服处理？考虑是什么？"——教科书答不了"故意不做什么"。真在场者与读报告者的区别在取舍、代价、反直觉的决定。
  • 决策权与治理结构是独立高价品类：lynk 单问 Volvo/Geely/领克"所有权、治理与决策权如何划分""优先级冲突时如何取舍"；豆包单问"总部/研究所/合资公司哪层有采购决策权"。知道"谁能拍板、按什么规则拍板"比产品参数值钱。
  • 提纲有稳定骨架（买方眼中懂行者的知识地图）：产品与方案 → 生态分工 → 市场拓展与报价 → 收入成本结构（ASP、计价）→ 竞争对照 → 团队架构与人数 → 战略控制点 → 行业展望。

4. 定价规则六条（检验清单）

  1. 有数字，且带口径和对照（26Q1 vs 25Q1、剔除出口、去除提成后的毛利）
  2. 有机制——每个数后面能答出"为什么、变化原因、瓶颈在哪"
  3. 有取舍和伤疤——"我们试过 X 失败了""我们故意不做 Y，因为 Z"
  4. 有决策链路和激励结构——谁拍板、KPI 怎么定、奖金怎么分
  5. 有边界感——确切知道的与只是听说的分开报（买方明确区分"知道确切数据"和"能聊"）
  6. 新鲜——离职三个月内、26Q1 的数；过期即贬值

四、应用：把"贵的东西"提炼进简历和面试

1. 诊断

"资深但面试没提炼出贵的东西"，用定价规则看很具体：简历和回答写的是职责和能力（免费信息），不是参数、机制和决策（付费信息）。买方（面试官）和这些需求单的买方是同一种人：他们为"在场者才有的具体事实"付费。

2. 简历改写规则

每条经历按"表格思维"重写，自问六个检验项：数字在哪？口径是什么？最硬的取舍是什么？我在决策链路哪一环？这条信息市场上要花钱才买得到吗？还新鲜吗？通不过检验的是占地方的免费信息。

❌ "负责 XX 业务的客服体系建设，搭建智能客服平台，显著提升效率"

✅ "从 0 搭建覆盖 X 个国家的客服体系（团队 X 人 + BPO X 家）；引入大模型辅助后 AHT 从 X 分钟降到 Y、采纳率 X%（口径：仅文本渠道）；主导'高风险操作必须转人工'的分级策略，退款类误赔率降 X%"

3. 面试答法：五元结构

  1. 数字 —— 先给结果的量
  2. 口径 —— 这个数怎么算的、不含什么
  3. 机制 —— 为什么是这个数、瓶颈在哪
  4. 对照 —— 同比多少、竞品多少
  5. 伤疤 —— 我们试过什么失败了、故意不做什么、为什么

另加一条边界声明："这个数我看板上看过，确切是 X；那个我只有二手信息，量级大概 Y。"——买方明文区分"知道确切数据"与"能聊"，诚实的精度本身是稀缺信号，装全知反而掉价。
