# 在例子中学习——模型何以落地

**缘起**：[在例子中学习](../关键文章/在例子中学习.md) 已立循环：少量样本建模型，马上用到更多例子，用中补全、手法练熟，反复无穷。感知 × 预测也写了。可「建模」本身还停在口号。本篇从建模的本质往下：模型是什么、为何几个例子就够、为何必须用、为何必须代谢、判据为何不是完备而是目标差距。
**用途**：给「在例子中学习」补上建模这一层；同时解两难——踟蹰不前（等学完、等案例最优再开始），不可全知（例子不齐、模型不全所以不敢用）。它与划小圈是两手，本篇不重写划场，见 [技能的两手](技能的两手——在例子中学习与划小圈.md)。

---

## 一、建模是什么：把无限收成此刻能动手的有限

模型不是世界的复印件。世界是网，网太密，人握不住。建模做的事只有一件：**抽出结构，舍掉偶然，留下此刻能预测、能出手的那一截。** 它是有损压缩，也是面向目标的投影——同一团现象，换一个目标，压出来的模型就不一样。点是面向目标的投影，模型也是。见 [点是面向目标的投影](点/点是面向目标的投影——不是知识的内禀属性.md)、[以有限应对无限](走向真实的交易/上篇-人怎么做/以有限应对无限-人类把握世界的方式.md)。

所以模型有两个身份，不要收成一个：

- **工具**：为当前目标服务的骨架。它不求像山，只求这一局里能用。
- **活物**：必须在运用里代谢。不用，就不是工具，是标本；不改，就不是活物，是教条。

以小控大有两只手。聚焦把力压到点上，偏行；建模把无限收成有限的抽象，偏知。在例子中学习，就是建模这只手最日常、也最底层的形态——不是先盖一座完备的楼，是先立一副最小骨架，立刻拿去撞世界。

这件事极深，深到几乎就是人怎么活：神经系统本来就在预测，类别本来就是对着需求往世界上投，不是感觉齐了再贴标签。见 [分类不是档案柜](../札记/分类不是档案柜：预测重构与体系的活性.md)。可它又极浅：几乎每个脑子都会。孩子看两次系鞋带就能试，学生听一道例题就能解一类题。不是天才特技，是默认引擎。深刻在本质，不在门槛。门槛低，恰恰说明这件事不是「学完建模理论才能做」，是人已经在做，只是常常做到一半就停——立了不用，用了不改，或者等齐了再立。

## 二、少量样本即可：例子少，是因为结构有限

少量样本能建模，不是因为那几个例子已经穷尽一类事物。是因为**现象无限，生成它的结构有限**。几个例子若仍转着同一副骨架，抽象感知一旦抓住「力与结构」，后面的千变万化都是这副骨架在不同条件下的展开。这和划小圈的同源是同一条骨：你收集的不是例子的表皮，是生成器。

因此「例子够不够」问错了。问的应当是：这几个例子里，骨架露了没有？露了，两个也够；没露，两百个也只是收藏。最优案例、齐全案例，是完备幻想的两种面孔。完备是不可全知强加给建模的指标。模型从来不需要全，它需要的是：对当前这一类、当前这一个缺口，已经能预测、能出手。

少量即可，还有一句反面：少量不是「随便一点就行」。感知若只记住辞藻、招式、这一盘棋的走法，样本再少也没有模型，只有记忆。少量样本的奇迹，发生在去芜存菁之后，不发生在囤积之前。

## 三、运用才是落地：模型的第三拍

模型有三拍，缺一拍就不是活模型：

1. **立**：从少量例子抽出骨架。感知。
2. **用**：立刻拿到更多例子上、拿到正在办的事上。预测撞现实。
3. **改**：偏差回来改骨架，手法在用中纯熟。代谢。

关键文章已经写了感知 × 预测。本篇补的是第三拍的身份：**运用不是模型建好之后的应用文，是模型本身的落地。** 在运用中，模型才发挥作用，才收到反馈，才算落实。知行合一在这里不是道德劝勉。王阳明那句「真正的知已经含着行的意向」落到建模上：说懂游泳却不下水，其实没有模型，只有一套关于游泳的说法。见 [到底有没有力量](知识/4%20到底有没有力量.md)。

立而不用，是自嗨。脑中那座精致的幻象可以自洽、可以漂亮，甚至可以在更多想象里「验证」自己。没有世界给的反馈，你分不清看见的是规律还是幻觉——[目标、差距与规律](走向真实的交易/2.1目标、差距与规律.md) 已经踩过这脚刹车。大语言模型会一本正经地胡说，根子也在这里：它从未下场，没有信息壁垒之外的第一手反馈。人若把模型停在脑子里，病是同一种。

用而不改，是蛮干。同一套骨架撞墙多次，偏差进不来，模型已经死了，人还当它是方法。

所以模型和运营是同一只钟，不是两段工期。「先建完模型再去运营」「先学够再做事」，把三拍拆成先立后用，第三拍永远排不上。运营在转，模型就该在转；目标变了、需求变了、世界给了新现象，骨架跟着改。同步，不是事后汇报。

## 四、没有完备，只有当前目标

模型没有完备态。完备是把模型当成世界的终稿。世界没有终稿，模型更不该有。

判据只有一句：**是否够到当前的目标，是否填上当前的差距，是否满足当前的需求。** 目标把无限的世界裁成一个有限的缺口；模型只对这个缺口负责。缺口填上了，这个模型就落地了——不是因为它已经正确、深刻、全面，是因为它在这一局里起了作用。见 [需求、目标与差距](走向真实的交易/2%20需求、目标与差距.md)。

精进永无止境。窗口向上永远开着：用得越久，骨架越准，手法越熟，能填的缺口可以更深、更远。但不需等待。窗口向下有一条沿：最小可用——能预测、能出手、能被反馈打到。沿一够，立刻用。等最优案例、等模型齐全、等「再看一本」，是把上沿误认成下沿，把永无止境读成永不准开始。

于是两难各破一半：

- **踟蹰不前**：以为要先全知才能动手。破法：少量即可立，立刻用，与需求校验。不够，反馈会告诉你差在哪，那才是下一截该立的。
- **不可全知**：以为例子不齐、模型不全，开始就是错。破法：判据不是全知，是目标差距。以小控大本来就承认不可全知——全知若可能，不必控，直接搬山。

两难是同一种病：把模型当成世界的完成图，而不是对着当前需求的工具。图越满越像完成了，其实在走向封闭。活性不是完美。体系楼如此，一个小模型也如此。见 [体系化之后，代谢是命](知识/3.1%20体系化之后，代谢是命——低内耗、怕固化，水无形是理想.md)。

## 五、不代谢即死亡：反馈是模型的血

模型依赖反馈。这句话比「要迭代」更硬：反馈不是优化选项，是活着的条件。

新陈代谢一停，模型就死。死相很像活着——说法还在，目录还在，甚至还在被引用。只是它不再吸收外部，不再被偏差改写，不再产出你原先产不出的判断。那就是自嗨的成熟态：内部越来越自洽，对外越来越聋。

代谢靠运用。运用把模型送进互动，互动带回边界——在哪一类例子上灵，在哪一类上不行。「不行」处比成功案例更值钱，因为它标出该换哪一块骨架。切断运用，代谢停在口号上。

所以「必须改进」不是鸡汤。模型从第一天起就不完备，改进不是从完备走向更完备，是从能用走向更贴这个目标。改进的方向由差距给，不由「还缺哪一章」给。差距在，改就有着落；差距填上了，这个模型的这一局就够了——下一局目标若变，再立、再用、再改。

## 六、和感知 × 预测怎么接

关键文章管循环怎么转：抽象感知抽骨架，仿真预测让骨架动，偏差回来改感知。本篇管循环为了什么、怎样才算一个活模型。

| | 关键文章《在例子中学习》 | 本篇 |
|---|---|---|
| **问** | 人怎么从几个例子长出一类本事 | 模型是什么，怎样才算落地 |
| **核心** | 感知 → 预测 → 验证 → 修正 | 立 → 用 → 改；用才落地，反馈才代谢 |
| **病** | 只感知不预测（纸上谈兵）；只预测不感知（盲目试错）；静止囤知识 | 立而不用（自嗨）；用而不改（蛮干）；等完备再开始（踟蹰）；要全知才敢用（不可全知） |
| **判据** | 循环有没有转 | 当前目标差距有没有被填上 |

两篇叠着读：循环是引擎，落地是引擎为何要转。引擎空转（圈里不打球）是技能两手里假勤奋乙；引擎不点火（等齐了再转）是本篇的踟蹰。都不是在例子中学习。

## 七、可迁移的几条

1. **模型是面向目标的有损压缩**，不是世界的复印件。同一团现象，目标换了，模型就该换。
2. **少量样本即可立。** 结构有限，例子不必齐，更不必最优。骨架露了就够。
3. **运用才是落地。** 立而不用是自嗨；模型与运营同一只钟。
4. **必须改进，因为从不完备。** 改进靠反馈，反馈靠运用。不代谢即死亡。
5. **没有完备，只有当前目标差距。** 精进无止境，但不需等待；与需求校验，看缺口还在不在。
6. **踟蹰不前和不可全知是同一种病**：把模型当成终稿。以小控大承认不可全知，所以才立刻用最小可用的那一截。
