# 技能的两手——在例子中学习，与划小圈

**缘起**：掌握技能，项目里一直并提两手——在例子中学习，与划小圈。可成稿里常把后者收成前者的「诀窍」，两手就糊成一只。本篇把分工钉死：在例子中学习是更宽泛的**建模循环**；划小圈是面对**大块、有体系、有积淀**的学问时，不被体系淹没的那一刀。
**用途**：技能论的配对定名；给 [在例子中学习](../关键文章/在例子中学习.md) 与 [划小圈——局部何以体会整体](划小圈——局部何以体会整体.md) 各安位置，并接到 [概念与技能](概念与技能——两种学习，同一种以小控大.md)。

---

## 一、两手，不是一招的两个绰号

技能要「会」，不是把说明书背完。会，是模型在身上转起来，碰到新情境能用、能改、能长。转起来靠两手：

| | **在例子中学习** | **划小圈** |
|---|---|---|
| **是什么** | 少量样本 → 建模型 → 立刻用到更多例子 → 偏差里修模型 → 再扩。无穷的建模循环 | 在庞大体系里圈出一块**同源缩影**，压缩外在、守住实质，走透到生成法则，从局部体会整体 |
| **回答的问题** | 人怎么从「几个例子」长出「一类本事」 | 体系已经大到能把人淹没时，圈划在哪，才不会被目录、招式、词表吞掉 |
| **宽窄** | 更宽泛。系鞋带、一道题型、一次工程案例，都是它 | 更特化。围棋、语言、太极、象棋、一门有百年积淀的专业——体系本身就是洪水 |
| **失败形态** | 静止地囤知识；只感知不预测（纸上谈兵）；只预测不感知（盲目试错） | 贪广求全，在开局百科、词表、拳套里淹死；或任意切片、阉割难点，圈小了整体仍出不来 |

两手咬合，不互相替代。划小圈圈出那一块之后，**圈里跑的仍是在例子中学习**：王兵残局还是靠一盘盘残局建模；一个句型还是靠一条条句子感知—预测—修正。划小圈决定「在哪一片水里游」；在例子中学习决定「游的时候模型怎么长」。没有划小圈，大学问里例子中学习会在汪洋上空转；没有在例子中学习，划小圈只是盯着一块碎片发呆。

## 二、在例子中学习：更宽泛的建模循环

人凭几个例子就能对一类事物上手——孩子看两次系鞋带，学生听一道例题解一类题。这不是魔法，是认知的默认引擎，可以收成一句：

**通过少量样本建立模型，马上应用到更多例子，在应用中丰富模型、使手法纯熟；以上反复迭代，无穷发展。**

它宽，是因为它不预设领域有多大。只要这类事有可抽取的结构，循环就能转：

1. **抽象感知**：从具体里抽出「力与结构」——去芜存菁，抓住规律骨架，不是记这一例的表皮。
2. **仿真预测**：让骨架在脑子里动起来——条件变了会怎样，我若出手对方会怎样。
3. **验证与修正**：预测撞上现实，偏差回头改感知；感知改了，下一轮预测更准。

缺预测，模型是死框架；缺感知，行动是瞎试。两者合成「感知→预测→验证→修正」——这就是不要以静止的方式处理问题：不是学够了再用，是先有一个最小可用模型，立刻用，用中长。

所以它比划小圈更底层、更通用。一门小手艺（打结、一道题型、一个API）往往划小圈还没必要启动，例子中学习已经够把人送过「会」的门槛。工程里一个完整案例是规律最好的容器，也是这只手：案例带着情境、反馈、偏差这些理论符号里被压缩掉的血肉，感知与预测在血肉里才转得快。

它的边界也清楚：例子再多，若从不抽取结构，只是收藏样本；模型建了若从不拿去撞新例子，只是静止的囤积。循环断在任何一截，都叫「在例子旁边待着」，不叫在例子中学习。

## 三、划小圈：大体系里那条防淹没的闸

围棋、语言、太极、象棋、一门有深厚积淀的专业——这些学问的可怕处，不只是「难」，是**已经大成体系**。定式可以印成砖头，单词可以堆成墙，拳架可以摆成套。人的本能是把体系当地图铺开：先把目录走完，再谈精深。结果几乎总是被淹没：

- **被目录淹没**：开局百科、语法全书、拳谱全套，每一页都「应该学」，注意力摊成薄雾，哪一页都走不透。
- **被招式淹没**：学的是外观的清单，不是生成这些外观的那几条法则。清单无限，法则有限；抱着清单走，永远走不完。
- **被「还没学完」淹没**：静止学习的焦虑在大学问里被放大——体系客观存在「学不完」，越想先覆盖再精，越证明自己永远不够格开始。

划小圈就是对着这股洪水落下的闸。它不否认体系庞大，它承认庞大，于是**拒绝以体系的尺度作为起步的尺度**。圈划在一块仍转着整体实质的局部：围棋的死活与官子，语言的一个句型用到脱口，太极收到几乎看不见却拳意仍在的那一拳，象棋的王兵残局。圈外的汪洋暂时不看。不是永远不看，是这块走透、法则露面、组块沉底之前，汪洋只是噪音。

为什么这样反而不丢整体？因为大体系之所以成体系，正是有限法则在无数位置上的展开。同源的小圈里，法则仍在转；吃透小圈，摸到的是生成器，不是这一块碎片。语言不是十万单词的和，是有限结构在无限句子上的展开——一个句型走透，感知语法已经在长；词表是后来填进结构的肉，不是结构本身。太极不是上百式的和，是同一条发力链在不同幅度、不同方向上的展开——一拳压缩到方寸，链还在，套就在这一拳里。围棋不是定式全书的和，是死活、厚薄、劫材这些生成法则在十九道上的展开——小棋盘上的死活走透，大棋盘才开始可读。

所以划小圈针对的，恰恰是「体系庞大」这件事。小手艺用它，往往杀鸡用牛刀；大学问不用它，建模循环会被例子的数量和目录的厚度先淹死——你不是没在例子中学习，是例子本身已经是汪洋，还没感知到结构，下一波样本已经把你冲走。

## 四、两手怎么接：圈外是洪水，圈里是循环

完整的技能习得，常常是嵌套：

```
大体系（围棋 / 语言 / 太极 / 专业）
    └── 划小圈：圈出同源缩影（防淹没，决定「在哪一片学」）
            └── 在例子中学习：在这一片里建模循环（感知—预测—验证—修正）
                    └── 走透 → 组块 → 意识腾空 → 从局部体会整体
                            └── 再把圈外扩一寸，循环仍在新圈里转
```

三句把关系说死：

1. **划小圈是选场，在例子中学习是下场打球。** 场选错（任意切片、阉割难点），球打得再勤，整体出不来；场选对却不下场（不建模、不拿新例子撞），圈是静物。
2. **在例子中学习可以单独成立；划小圈在大学问里几乎不能单独成立。** 系两次鞋带，建模循环已够。十九道围棋没有小圈，建模循环会在「再看一页定式」里空转一生。
3. **外扩不是改换引擎，是换一片仍同源的水。** 王兵熟了加马，一个句型熟了加嵌套，一拳熟了开下一式——圈变大，圈里跑的还是同一套感知—预测—修正。贪广是同时开许多个没走透的圈，不是外扩。

模仿在这两手里的位置：它常常是在例子中学习的起手——例子不够时，人先借一个活的样本（高手的一盘棋、一句发音、一记拳）。模仿提供血肉，抽象感知从血肉里抽骨架。划小圈则约束模仿的范围：大学问里「模仿一切」等于被体系淹没；模仿这一拳、这一句、这一块死活，才是有闸的模仿。

## 五、淹没与两种假勤奋

大学问里最常见的假勤奋，正好打在两只手上：

**假勤奋甲：只铺例子，不划圈。** 刷题、刷词、刷定式、刷拳套。看起来最像「在例子中学习」，其实循环的第一环——抽象感知——从未发生，样本在增加，骨架没露面。体系越大，这种勤奋越像用功，淹没也越彻底。

**假勤奋乙：只划圈，不在圈里建模。** 把范围缩得很小，却不走感知—预测—修正，也不走透到法则。每天「只练这一块」，块仍是外观。圈是小了，实质没挖出来，局部体会不到整体——闸是落下了，闸门里没有水流。

真功夫是两手同时在：闸落下（同源、不阉割），水在闸门里转（少量例子建模，马上用到新例子，偏差里长）。转得足够久，组块沉底，整体作为结构浮出来——那才是划小圈许诺过的「从局部见整体」，也才是在例子中学习许诺过的「模型变成第二天性」。

## 六、可迁移的几条

1. **掌握技能是两手，不是一招。** 在例子中学习＝宽泛的建模循环；划小圈＝大学问里防淹没、从同源局部见整体。
2. **体系越大、积淀越深，越要先落闸，再在闸里循环。** 围棋、语言、太极是典型；目录型、招式型、词表型的「学完再精」是淹没的温床。
3. **小手艺往往只需在例子中学习；大学问两手都要。** 不要把划小圈当成所有技能的口头禅。
4. **圈里仍然是例子中学习。** 划小圈不替代建模，它指定建模发生的那一片。
5. **两种假勤奋**：只铺例子不抽骨架；只缩范围不走透。淹没与空转，是同一失败的两面。
