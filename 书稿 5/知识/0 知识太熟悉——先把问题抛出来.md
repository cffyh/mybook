# 知识太熟悉——先把问题抛出来

**缘起**：知识这个概念太常见、太熟悉。熟悉不是懂。天天用、天天追、天天敬，一问「我知道」时手里到底是什么，就散。从「何为知识」起手更糟——读者会滑回存货、力量、过时那些口头禅。柏拉图追问过三次，每次都经不起再问。本篇不立工作定义，不给四面格子。**得先把问题抛出来**：让嘴里那些拧着的话出场。总病就一句——**一句真话拿去取消另一句真话。** 两端都真，拧在同一个词上，于是不是崇拜就是轻视，不是死记就是拆楼。
**用途**：只抛，不劈完。四组标题即后面四篇的篇名。书稿4 [第一章　知识](../../书稿%204/第一章_知识.html) 是平实长读；总论 [知识体系](../总论/1.3%20知识体系——无用之用与可生长的坐标.md) 从临场倒推用法。本篇是簇的入口。

## 一、它到底是什么，传下去的又是什么

人们混着说：知识＝脑子里的存货；＝世界的摹本；＝概念／原理／理论；＝逻辑、判断、见识；＝技能；＝要点。词越熟，越不拆。

| 人们说 | 对面那句 | 没劈开会怎样 |
|---|---|---|
| 写下来就是认识的全部 | 书永远不像现场，所以书失败了 | 怪教材，或幻想下一次能编全 |
| 能开卷的都能搬家 | 会做的也能开卷学会 | 把技能当知识背，把知识当技能泡 |
| 懂得多就是想得清楚 | 记得很多仍糊涂 | 学识当见识，存货当判断 |
| 今天的结论就是定论 | 以后会过时，所以现在怎么说都行 | 封成圣经，或相对主义 |

真问题三问。我说「我知道」时，手里到底是哪一截？能交给后人的是哪一截？丢掉的细节是事故，还是一写下来就付掉的物性？

劈开见 [它到底是什么，传下去的又是什么](1%20它到底是什么，传下去的又是什么.md)。

## 二、为什么摆到面前了，仍不是我的

人们说「学习知识」，像搬包裹。考试加重这病：范围已框、答案已备，再存一遍就得分。现实没有标准答案，只有问题能否解决。

| 人们说 | 对面那句 | 没劈开会怎样 |
|---|---|---|
| 知识可以传授，所以可以转移 | 学了还不会，所以传授没用 | 要么怪老师，要么放弃继承 |
| 一听就懂＝掌握了 | 4P 听着简单，定价仍没手 | 熟悉感当能力 |
| 必须重建＝不必读前人 | 不重建＝把目录再存一遍 | 从零摸，或搬运得分 |
| 能讲清楚＝能下手 | 零件齐全＝家具立得住 | 停在认识，进不了验证 |

真问题：可传授和可转移是不是一回事？熟悉感为什么这么像掌握？重建若跳不过去，根是态度，还是传来时已经丢了、各人地基又不同？

劈开见 [为什么摆到面前了，仍不是我的](2%20为什么摆到面前了，仍不是我的.md)。

## 三、要体系，又嫌体系

这组日常最响。人们要么当 App——今天这题章节里没有，整栋拆；要么当圣经——课纲即真理。建楼的人被骂过时，拆楼的人手里只剩碎片。

| 人们说 | 对面那句 | 没劈开会怎样 |
|---|---|---|
| 体系要完备 | 知识永远盖不住世界 | 用内容的缺口否掉图 |
| 体系要稳定 | 知识必须可修正、可淘汰 | 用砖会改否掉骨架，或用骨架硬封死砖 |
| 终局只有砖值钱，所以建楼多余 | 没有楼，砖无从生产、无从压力测试 | 只拆不建 |
| 过时了所以没用 | 有体系图所以会做事 | 当 App 拆，或当临场第一下 |

真问题：「过时」打的是解题期待，还是结构职能？完备说的是穷尽世界，还是对内自洽、对外可挂、空白标得出？稳定的是咬合方式，还是砖永真？

劈开见 [要体系，又嫌体系](3%20要体系，又嫌体系.md)。临场倒推何时用体系，见总论 [知识体系](../总论/1.3%20知识体系——无用之用与可生长的坐标.md)，不在本簇重写。

## 四、到底有没有力量

培根：「知识就是力量」——流传越广越不掂量。出场之后另一句也很响：过往知识没啥用，留下的是能力。两句都真，最容易收成一句假话。这组最密。

| 人们说 | 对面那句 | 没劈开会怎样 |
|---|---|---|
| 知识就是力量 | 知识无用，能力才重要 | 盲目崇拜，或用图外否图内 |
| 学会知识就是目的 | 知识只是手段 | 求学换位永不到期，或反过来取消继承 |
| 知识过时，所以不必掌握 | 掌握了就永远够用 | 该继承的没继承，或存货当终身饭票 |
| 知道了就该能做到 | 做不到说明其实不懂 | 再学一章，或自我道德化 |
| 站上巨人的肩就行 | 必须自己从零摸 | 腿软的搬运，或付不起的拒绝继承 |

这里不止一对。手段和目的会换位，求学阶段合法，出场要换回来——换回来不是知识没用了。知识本身的威力，很多时候仍然极重要；具体结论对不上这一局时，留下的往往才是能力。两种「知识没用」也不要混：没掌握，差的是力量有无；掌握了但对不上，差的是内容贬值。懂得多不等于想得清楚；知道不等于做到。

真问题不是「知识有用还是能力有用」。是：这一局还在不在已有结晶覆盖里？求学那次换位到期了没有？从知到行，缺的是再一章，还是身上的手？

劈开见 [到底有没有力量](4%20到底有没有力量.md)。

## 五、读序：四组不是并列

先问它是什么。钉住之后，后三组已经被决定，不是另外三个话题。

1. **需要吸收，以及如何吸收**——传的是符号，细节已丢，人必须接到自己身上再跑。见第二组。
2. **最大特性是结构化**——知识是世界的抽象；结构化来自世界的结构实在，也体现世界的结构实在。需要抽象、可以抽象；失败常在不够具体。临场用分析 + 演绎把知识送回这一手。见第三组。
3. **最大禀赋是精华**——结晶才传得动。精华决定适用场合的威力，也决定局限。见第四组。

跳过第一组，后面会把符号当实物，三决定无处生根。跳过吸收，结构化是别人的楼。跳过结构化，精华是散词条。跳过精华，前三组停在认识论，到不了用。

本篇只负责让熟悉的东西重新可疑。工作定义、三决定、三步作业、图内图外——一律在同题四篇里钉。不要用本篇的表去代替劈开。
