# 知识这一簇

知识太常见、太熟悉。熟悉不是懂。本簇不从「何为知识」起手，**先把问题抛出来**。

**先读**：[知识太熟悉——先把问题抛出来](0%20知识太熟悉——先把问题抛出来.md)

总病：一句真话拿去取消另一句真话。四组标题即四篇篇名。只抛不劈完的在入口；劈开在同题各篇。

```
它到底是什么，传下去的又是什么
        │
为什么摆到面前了，仍不是我的
        │
要体系，又嫌体系
        │
到底有没有力量
```

| 组 | 篇 | 一句 |
|---|---|---|
| 一 | [它到底是什么，传下去的又是什么](1%20它到底是什么，传下去的又是什么.md) | 结合点；能传的是符号；丢失是物性 |
| 二 | [为什么摆到面前了，仍不是我的](2%20为什么摆到面前了，仍不是我的.md) | 消化＝重建；可传授，不可转移 |
| 三 | [要体系，又嫌体系](3%20要体系，又嫌体系.md) | 职能要硬，内容要活；当 App 与当圣经都死 |
| 四 | [到底有没有力量](4%20到底有没有力量.md) | 手段不是目的；图内靠知识本身，图外留下的往往是能力 |

读序按箭头。跳过第一组，后面会把符号当实物；跳过第二组，体系是别人的楼；跳过第三组，力量是散词条；跳过第四组，前三组停在认识论，到不了用。

书稿4 [第一章　知识](../../书稿%204/第一章_知识.html) 按「何为 / 威力与局限 / 重建 / 知与行」做平实长述，是成品。本簇把同一批钉子收成四组问题，并补上书稿4没单独立住的**要体系又嫌体系**（完备 vs 中间结论）。不重写那一章。

总论 [知识体系——无用之用与可生长的坐标](../总论/1.3%20知识体系——无用之用与可生长的坐标.md) 不是第五组。它从临场倒推：**何时用**（乱了／大了／失灵了）、入口为何是划小圈。四组是问题与劈开；1.3 是用法。
