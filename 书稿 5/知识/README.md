# 知识这一簇

知识太常见、太熟悉。熟悉不是懂。本簇不从「何为知识」起手，**先把问题抛出来**。钉住是什么之后，后三件事已经被决定——不是四组并列。

**先读**：[知识太熟悉——先把问题抛出来](0%20知识太熟悉——先把问题抛出来.md)

总病：一句真话拿去取消另一句真话。只抛不劈完的在入口；劈开在同题各篇。

```
它到底是什么，传下去的又是什么
        │
        ├── 需要吸收，以及如何吸收
        ├── 最大特性：结构化（来自并体现结构实在）→ 体系性与不完备性同根
        └── 最大禀赋：精华 → 适用场合的威力，与局限
```

| | 篇 | 一句 |
|---|---|---|
| 是什么 | [它到底是什么，传下去的又是什么](1%20它到底是什么，传下去的又是什么.md) | 结合点；能传的是符号；丢失是物性。数据链是一条常见加工链，不是唯一来源；信息不升也能为决策提供依据 |
| 吸收 | [为什么摆到面前了，仍不是我的](2%20为什么摆到面前了，仍不是我的.md) | 消化＝重建；可传授，不可转移。没有自己的体系，消化无处落脚 |
| 结构化 | [要体系，又嫌体系](3%20要体系，又嫌体系.md) | 来自并体现结构实在；个人那一截：过程是消化器官，切片是历史上认知的成果（与能力／实力同构）；砖必须代谢；**活性不是完美** |
| 精华 | [到底有没有力量](4%20到底有没有力量.md) | 精华决定适用场合的威力，也决定局限 |

跳过是什么，后面会把符号当实物。跳过吸收，结构化是别人的楼。跳过结构化，精华是散词条。跳过精华，前三组停在认识论，到不了用。

书稿4 [第一章　知识](../../书稿%204/第一章_知识.html) 按「何为 / 威力与局限 / 重建 / 知与行」做平实长述，是成品。本簇把同一批钉子收成「是什么 → 三决定」，并补上书稿4没单独立住的**体系性与不完备性**。不重写那一章。

总论 [知识体系——无用之用与可生长的坐标](../总论/1.3%20知识体系——无用之用与可生长的坐标.md) 不是第五组。它从临场倒推：**何时用**（乱了／大了／失灵了）、入口为何是划小圈。1.3 是用法。临场里成熟／前沿怎么拆、体系三时态，见 [成熟与前沿](../总论/1.21%20成熟与前沿——不可套用，必须沿用.md)。
